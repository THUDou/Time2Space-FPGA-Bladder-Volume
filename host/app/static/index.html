  1. 开机 — PYNQ-Z2 上电（烧录线或 12V 适配器），确认 DONE 灯亮；双击 启动上位机.bat 或运行 python host/app/app.py，浏览器自动打开本界面。
  2. 选模式 — 硬件没接好就用默认「演示模式」（合成回波，界面完全同构）；硬件就绪点「有线串口」或「蓝牙串口」。
  3. 连接 — 串口模式下拉选 COM 口（蓝牙需先配对出 COM 口），波特率 460800，点「连接」。状态胶囊变绿即为 LIVE。
  4. 演示讲解三句话 — ①左边是 B 模式扫查图，前后壁两条亮弧之间黑色就是尿液；②右边 9 个通道各自测距，球面拟合出膀胱；③大数字就是尿量，单位 mL，趋势图看充盈变化。
  5. 答辩兜底 — 即使演示当天硬件没到位，演示模式可完整走流程：扫查动画、9 通道波形、三维重建、尿量趋势全部在动，直接按上面三句话讲。
  6. 收尾 — 断开连接 → 关闭浏览器 → Ctrl+C 停服务。

方案 A · 蓝牙无线（HC-05 / HC-04，4 针）

接好后 PC 打开蓝牙 → 配对 HC-05（默认 PIN 1234 或 0000）→ 设备管理器出现 COM 口 → 上位机选「蓝牙串口」连接。

波特率设置：模块默认 9600，需先用 USB-TTL 进 AT 模式（EN/KEY 拉高）发送 AT+UART=460800,0,0（HC-04 同理 AT+UART=460800），再切回透传。

方案 B · 有线直连（USB-TTL，烧录线外的数据线）

CH340 / CP2102 / PL2303 均可，注意拨到 3.3V 电平档。插上电脑自动装驱动出 COM 口，上位机选「有线串口」连接。

烧录线能不能直接传数据？ 板载 Micro-USB 烧录线负责供电 + PS 控制台；PL 测量数据从 JB8 出，所以要么用本方案的 USB-TTL，要么用方案 A 蓝牙——两者对上位机来说都只是「一个 COM 口」。

部件供电说明
PYNQ-Z2Micro-USB 烧录线 或 12V 适配器纯数字链路演示时烧录线供电即可；接模拟前端建议 12V
ADC 采集板独立 5V ≥ 1A+ → H1.1，GND → H1.2/H1.4，不从 PYNQ 取电
TRX-9 收发板+5V（初赛）/ +12V（提 SNR）J1.2=+5V、J1.3=GND；J2 短 1–2（5V 发射）
HC-05 蓝牙VCC → 5V（或 3.3V）模块板载稳压，5V 更稳；与 PYNQ 共地
USB-TTLUSB 自供电无需额外电源

结论：演示模式 / 纯数字自测只需要一根烧录线；完整收发链路需要 5V + 12V 两路外接电源并全部共地。数据传输不占用烧录口，实时性由 460800 串口保证（约 11 次完整估计/秒）。
