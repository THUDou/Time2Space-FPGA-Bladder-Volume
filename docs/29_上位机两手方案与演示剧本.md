# 上位机两手接线方案与演示剧本（手把手）

> 版本 v1.0 · 2026-11-03 · 配套 `host/app/` 上位机
> 面向：三位负责现场操作的同学（零基础可照做）

---

## 0. 一分钟看懂两手方案

| | 方案 A · 蓝牙无线 | 方案 B · 有线直连 |
|---|---|---|
| 硬件 | HC-05 / HC-04（4 针：VCC GND TXD RXD） | USB-TTL 小板（CH340/CP2102，3.3V 档） |
| 接线 | JB8(W15)→HC-05 RXD；GND→GND；VCC→5V | JB8(W15)→USB-TTL RXD；GND→GND |
| PC 侧 | 蓝牙配对 → 出 COM 口 | USB 插口 → 出 COM 口 |
| 优点 | 无拖线，演示干净 | 即插即用，最稳 |
| 上位机操作 | 选「蓝牙串口」+ COM 口 → 连接 | 选「有线串口」+ COM 口 → 连接 |

**软件侧两方案完全一样**：都是「电脑上的一个 COM 口」，波特率统一 **460800 8N1**。
没硬件时用「演示模式」，界面与实测完全同构，可完整走演示流程。

## 1. 方案 A · 蓝牙（HC-05 / HC-04）接线

```
PYNQ-Z2                HC-05 / HC-04
─────────              ─────────────
JB8 / W15 (UART_TX) ──► RXD
GND                  ──► GND
5V（Arduino 排针 5V） ──► VCC
                       TXD 悬空（只用上行）
```

要点：
1. **信号只有一根**：FPGA 的 UART_TX（JB8 针 8 / 管脚 W15）接模块的 **RXD**。
2. **必须共地**：PYNQ GND 与模块 GND 连一起，否则乱码。
3. **供电**：模块 VCC 接 5V（板载稳压）最稳；只有 3.3V 也能凑合用。
4. **TXD 悬空**：我们的数据只从 FPGA 发到 PC，不回传。
5. **配对**：电脑蓝牙搜索 HC-05（PIN `1234` 或 `0000`）→ 配对成功出现 COM 口。
6. **波特率**：模块出厂默认 9600，**必须先改成 460800**，否则收不到数据：
   - 用 USB-TTL 接模块，EN/KEY 引脚接 3.3V（进 AT 模式），USB-TTL 以 38400 打开；
   - 发 `AT` 回 `OK` → 发 **`AT+UART=460800,0,0`**（HC-04：`AT+UART=460800`）；
   - 断电重启，拔掉 KEY 线，回透传模式即可。

## 2. 方案 B · 有线（USB-TTL）接线

```
PYNQ-Z2                USB-TTL (CH340/CP2102)
─────────              ──────────────────────
JB8 / W15 (UART_TX) ──► RXD（拨到 3.3V 电平）
GND                  ──► GND
```

要点：
1. 只有两根线（信号 + 地），USB 插电脑即供电、即出 COM 口。
2. **电平必须拨 3.3V**，5V 档会损伤 FPGA IO。
3. 460800 波特率下实时传输无压力（≈11 组完整估计/秒）。

## 3. 供电答疑（要不要外接电源？烧录线能不能传数据？）

| 问题 | 答案 |
|---|---|
| 装置要不要外接电源？ | **纯数字演示/自测：不用**，一根 Micro-USB 烧录线即可。**接完整收发链路：要** —— ADC 板独立 5V≥1A（→H1.1），TRX-9 初赛 +5V（J1.2）、决赛提 SNR 用 +12V（J1.1），全部共地。 |
| 烧录的数据线能不能实时传数据？ | **烧录线本身不能直接传 PL 测量数据**（它负责供电 + PS 控制台）。测量数据从 JB8 出，走方案 A 蓝牙或方案 B USB-TTL 都是实时的（460800，约 11 次/秒）。 |
| HC-05 供电从哪取？ | PYNQ Arduino 排针 5V（或 3.3V），电流很小（~30mA），与 PYNQ 共地。 |
| 上位机要不要装驱动？ | USB-TTL 插上自动装 CH340/CP2102 驱动；蓝牙走系统自带。Python 只需 `pip install pyserial`（演示模式连这个都不用）。 |

## 4. 上位机启动

```bash
# 零依赖（演示模式）
python host/app/app.py          # 浏览器自动打开 http://127.0.0.1:8787/

# 或双击
host/app/start_hostapp.bat

# 接真实串口前装一次
pip install pyserial
```

## 5. 演示剧本（答辩手把手，照念即可）

**上场前 3 分钟检查**
1. 双击 `start_hostapp.bat`，浏览器弹出界面 → 看到扇形图在扫、数字在跳 = 正常。
2. 硬件就绪：按 §1/§2 接好线 → 界面选「有线串口」或「蓝牙串口」→ 选 COM 口 → 点「连接」→ 右上胶囊变绿。
3. 硬件没就绪：什么都不用动，**演示模式直接开讲**。

**讲解三句话（评委面前）**
1. 「左边是超声 B 模式扫查图——前后壁两条亮弧之间黑色无回声区就是尿液。」
2. 「右上 9 个通道各自测回波深度，球面拟合重建立体形态，大数字就是实时尿量，单位毫升。」
3. 「全链路在 FPGA PL 里实时跑：发射、采集、包络、TOF、组帧，460800 串口回传，每秒约 11 次完整估计。」

**可能被问的问题**
- 「数据怎么出来的？」→ 蓝牙 HC-05 或 USB-TTL，对上位机都是标准串口，460800 8N1。
- 「没接探头怎么有数据？」→ 内置合成回波引擎与实测帧格式完全同构（AA55…0D），演示模式用于链路展示；实测模式走真实硬件。
- 「精度多少？」→ 测距分辨率由 25MSPS 采样定（单点 29µs ≈ 2.2cm 声程，包络内插后 mm 级），容积走 9 点球面拟合。

**收尾**：点「断开」→ 关浏览器 → 命令行 Ctrl+C。

## 6. 故障速查

| 现象 | 处理 |
|---|---|
| 打开网页全灰 | 看命令行是否报错；换端口 `python app.py --port 8790` |
| 串口下拉是空的 | `pip install pyserial` 后重启程序；蓝牙先配对 |
| 连上没波形 | 查波特率 460800；HC-05 是否已 AT 改速；JB8 与 RXD 是否接对 |
| 数字乱跳 | 共地没接好；USB-TTL 误拨 5V 档 |
| 浏览器没自动开 | 手动访问 http://127.0.0.1:8787/ |
